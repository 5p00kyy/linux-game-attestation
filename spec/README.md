# Draft Specification

This directory contains the work-in-progress Linux Game Attestation profile.
It is not an IETF standard and has not been reviewed or accepted by a game
publisher or anti-cheat vendor.

- `profile.md` defines roles, encoding, claims, validation, and privacy.
- `profile.cddl` defines the draft CWT/EAT claims set.
- `policy-schema.cddl` defines a minimal reference-policy document.
- `vectors/` contains semantic examples and, later, signed interoperability
  vectors.

Normative words are used to make implementation requirements testable. They do
not imply standards-track status.
